## Verified behavior

- Missing, insufficient, stale, and future evidence do not become false Low concern.
- Stable evidence becomes Low only with three distinct recent observation times.
- Combined trends produce an evidence-linked Medium concern before absolute demo limits.
- A configured High reading raises concern immediately at the boundary.
- Concurrent reading retries create one active episode; severity can rise once and does not silently downgrade or resolve.
- Anonymous, forged, expired, and unassigned sessions cannot record care responses.
- Action payloads cannot supply a spoofed actor. The server enforces lifecycle order and separate action/resolution text.
- Exact action retries create no extra history; changed payloads under the same identity conflict.
- Older replay cannot reopen a resolved episode; newer concerning evidence can open a new episode.
- Alerts, acknowledgement history, assessments, and local sessions survive database close/reopen.
- First-milestone databases migrate without losing readings; repeat initialization does not reapply migrations.
- Desktop and 320/768px layouts retain concern and care controls without page overflow.

## Review refinements

Kept current assessment separate from episode resolution and highest recorded episode severity. Condensed the primary concern explanation while retaining all supporting reasons/event IDs in expandable evidence. Text survives failed action submissions; exact retries retain their request identity until confirmed or rejected.

Excluded `.data/` from Next.js server output traces after build inspection identified local test database files being traced. Runtime databases are state and must not be packaged with application assets. The refreshed production API returned Waiting/Unknown and no alerts for the empty local database.

The final build passed; seven server trace manifests contained zero `.data/` entries. Turbopack still emits a compile-time pattern-size warning while analyzing the dynamic local database directory. That local build-performance warning remains visible; no runtime database files are packaged.
